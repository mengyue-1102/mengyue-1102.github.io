# XJTLU Major Selection AI Assistant
ADS401 Presentation 2 Project

## Project Overview
This is an AI agent for XJTLU students and applicants. It helps users search, compare and learn about XJTLU undergraduate majors.
AI Agent Link: https://aiagent.xjtlu.edu.cn/product/llm/mall/application/d40ej496i3uelisjb0q0/chat

## Evaluation Design Summary
We run a mixed-method usability evaluation.
Target users: XJTLU Year 1 students and high school applicants for XJTLU.
Research Questions:
1. Can this AI assistant help users get useful major information quickly?
2. What usability problems do users meet when chatting with this AI agent?
3. What is users’ overall satisfaction with this AI tool?

Evaluation methods:
- Semi-structured interview (qualitative data)
- SUS usability questionnaire (quantitative data)
Sampling method: Purposive sampling, small pilot study.
